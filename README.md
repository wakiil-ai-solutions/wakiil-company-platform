# Wakiil AI Solutions

Wakiil designs and operates controlled automation systems that help businesses work faster, safer, and with more control.

This repository contains the public Wakiil company platform: a bilingual English/Somali marketing site and a clearly labeled technical demonstration.

## What Wakiil can design and implement

- AI automation consultancy
- Custom integrations
- Workflow automation
- Digital operations assistants
- Business operating systems

## Public proof boundary

The interactive demo uses controlled or synthetic data. It is an internal technical demonstration, not a customer case study, production integration, or claim of customer results.

No customer software, credentials, private infrastructure, customer data, or internal operational repositories are included here.

## Run locally

```powershell
npm install
npm run dev
```

The site uses hash routes so it works under the GitHub Pages project path:

- `#/`
- `#/solutions`
- `#/method`
- `#/proof`
- `#/security`
- `#/about`
- `#/contact`
- `#/demo`

## Deployment

GitHub Actions builds the Vite site and deploys the `dist` artifact to GitHub Pages. The project base path is configured for `/wakiil-company-platform/`.
